# Wedding Invitation — May 8, 2027

A minimalist, animated wedding invitation website in emerald green, ivory and white.
Plain HTML/CSS/JS — no build step. Open `index.html` in a browser, or host the folder
on GitHub Pages, Netlify, Vercel, etc.

## Customize
- **Names / monogram / venue / story / schedule**: edit `index.html` (search for `Carlo`, `Althea`, `C<em>&amp;</em>A`, `Manila Cathedral`).
- **Date & time for the countdown**: `WEDDING_DATE` at the top of `script.js`.
- **Colors**: CSS variables at the top of `styles.css`.
- **RSVP**: the form currently only shows a thank-you message; hook it up to Formspree,
  Google Forms or your own backend where the `TODO` is in `script.js`.
